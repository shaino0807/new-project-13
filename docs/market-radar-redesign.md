# 市場雷達改版決策

## 正式方向

- 首頁以已核准的淺色「市場雷達」畫布為主，不沿用舊版大型漸層 Hero。
- 保留核准畫布中的產業方塊熱力圖；不加入第二張畫布的其他區塊。
- 網站名稱維持「台股波段觀察分析庫」。
- 首頁順序固定為：導覽與搜尋、資料狀態摘要、產業熱力圖、研究篩選器、可信排行榜。
- 桌面版使用密集表格並固定名次與股票欄；手機版改成資訊卡、橫向產業方塊及可收合篩選器。

## 資料與評分邊界

- 排行榜只使用本站公開資料模型與既有評分，不匯入或重算 TradingView、Dipping.ai 的資料。
- Dipping.ai 與 TradingView 只作資訊架構、欄位與操作方式參考。
- 排名資格維持：有總分、有報價日、資料覆蓋率至少 60%，且沒有過期資料。
- 可重現排序維持：主分數、資料覆蓋率、報價日期、股票代碼。
- 產業熱力圖只彙總目前可控評分批次，清楚標示批次範圍，不宣稱全市場即時廣度。
- 左側與右側使用不同的「策略匹配分數」作第一層篩選；它不是買賣訊號。
- 個股的箱型、突破、假突破、支撐壓力及多空訊號，仍只交由 `kline-long-short-signal` 深度分析流程處理。

## 顧客端進度原則

- 顧客只看到「請稍候」、百分比、簡短階段名稱、是否可離開頁面與完成／失敗狀態。
- 不顯示工作編號、Skill 名稱、內部階段鍵、成功／失敗筆數或後端串接細節。
- 內部工作資料仍保留供除錯與稽核使用，但不直接呈現在顧客畫面。

## 第一版範圍

- 使用目前可靠的可控批次與最近一次完整快照。
- 不新增登入、付費或外部資料授權。
- 篩選偏好只儲存在使用者瀏覽器。
- 本次只做本機程式碼、測試、畫面驗證與獨立 Git 提交；不推送、不部署。
