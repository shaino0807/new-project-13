# 宏觀風險掃描：付費資料源採購待辦

狀態：**暫不採購**。在本機與已部署版本完成規則、快照續跑、資料日期與手機介面驗證後，再由專案負責人決定是否啟用。

## 採購前共同驗收條件

- 先完成連續至少 20 個交易日的掃描快照，確認 17 項契約、資料日期、VIX/A-D 硬觸發與焦點排序均可重現。
- 在測試環境驗證 API 或授權報告可提供：目前值、資料日期、來源 URL 或報告識別、更新頻率與授權範圍。
- 確認公開網站是否可顯示數值、歷史資料、摘要或僅能顯示狀態；不得把供內部使用的授權內容直接公開。
- 接入前須先測試來源失效、額度耗盡、延遲與資料衝突時，系統仍回傳「未知」而非沿用猜測值。
- 憑證只放在部署平台的秘密設定；不得寫入 Git、`.env.local`、前端或報告。

## 優先資料源

| 優先 | 資料源 | 補足指標 | 採購／授權時要確認 | 啟用門檻 |
|---|---|---|---|---|
| 1 | NAAIM | NAAIM Exposure Index | 當期值、資料日期、是否可在公開頁面轉載 | 可取得當週原始或授權報告；否則維持未知 |
| 2 | AAII | Investor Sentiment、Asset Allocation | 兩種調查的更新頻率、授權與 API／下載方式 | 可保留 Bullish、Bearish、配置比及其日期 |
| 3 | GuruFocus | Insider Buy/Sell、Margin Debt/GDP 交叉核對 | 個人／商業授權、反爬限制、可否自動擷取 | 取得可重複驗證的當期讀數與日期 |
| 4 | BofA Flow Show 或合法再授權資料商 | BofA Bull & Bear | 是否可存取原始 Flow Show、公開展示限制 | A/B 級原始證據；若採 C 級轉載，需兩家獨立當週來源、同時列出原報告名稱與日期，數值差距不得超過 0.1 點 |

## BofA 信心分級

- A：官方原始資料。
- B：具授權的原始報告，含報告日期與當期值。
- C：可信媒體轉載，且有原始報告名稱、日期與數值。需要兩家獨立、當週、數值差距不超過 0.1 點才可使用。
- D：無日期、無法追溯或無法交叉驗證的資訊；一律不使用。

## 啟用後回歸測試

- BofA 缺 A/B 或合格雙 C 證據時，燈號與硬觸發必須都是「未知」。
- 授權過期、來源 HTTP 失敗或資料日期不符時，舊數值不可被當成最新值。
- 採購資料僅改善可用性，不得改變既定門檻：VIX 連續 2 個交易日、A/D 60 日／1%／3 日，以及 3/7 分批降風險門檻。
