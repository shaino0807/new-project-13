## 本次踩坑

- Yahoo Finance 依序探測 `.TW`、`.TWO` 與兩個主機時，錯誤市場後綴的預期 404 也會被計入外部請求失敗；438 次 Yahoo 失敗不等於 438 檔股票失敗。
- 真實 250 檔試跑有 39 檔重試後仍無 Yahoo 日線與交易所報價。完整公司目錄不等於目前可交易母體，兩者必須分開揭露。
- AppDeploy 可能在部署已為 `ready`、前後端錯誤為 0 時不回傳 E2E 欄位，使安全部署 worker 以失敗碼結束；必須再以公開 HTML、正式 API 與快照 ID 交叉驗證。
- registry 指向 `complete` 快照不代表歷史內容仍符合現行政策；持久化快照在每次讀取時也必須重新驗證 60% 覆蓋率、報價日期與無過期資料門檻。
