## 已選定的方向

規劃採用「本機負責更新與計算、雲端保存完整資料、網站持續提供查詢」。先完成不新增費用的準備，再確認雲端規格與實際價格。

主要資料、更新進度與分析結果都放在雲端。本機只保留程式、憑證及有限日誌；資料分批放入記憶體處理，不另外保存全市場資料庫副本。憑證只留受保護設定，不進 Git、公開網頁或 Obsidian。

| 位置 | 工作與保存內容 |
| --- | --- |
| 本機 | 分批抓取、清理、分析計算、把結果寫入雲端；暫存有界，不累积原始全集 |
| 雲端 PostgreSQL | 股票歷史、財報與營收、新聞查詢狀態、分析快照、來源日期、額度帳本、更新進度及失敗證據 |
| 雲端讀取 API | 讀取已保存結果、提供搜尋與頁面所需資料；瀏覽不觸發來源抓取或重新評分 |
| 網站 | 呈現結果、日期、缺漏、更新狀態及錯誤／重試入口 |

本機關機、睡眠或更新程式停止後，雲端網站仍可提供最後成功保存的結果；新的資料更新會停止。重新開機須依持久 checkpoint 接續，不能將未更新資料改標為今天。達成每日更新需要本機每日有足夠執行時間，不宣稱這是全天自動更新方案。

## 第二階段：雲端建置與小批驗收

1. 依第一階段估算決定 PostgreSQL 規格、儲存量、備份／恢復與監控，查核實際帳號報價，取得付費資源建立確認。
2. 候選位置為已確認的 Render「My Workspace」、新加坡。優先評估沿用既有 Starter 作讀取 API；若需要修改現金流 repo／服務，先呈現跨專案範圍並確認，不能變更其 repo 綁定來取代現金流程式。
3. 台股 schema／權限與現金流資料隔離；本機使用 TLS 的雲端連線，網站只經由 API，前端不持有資料庫憑證。雲端內部 API 優先使用同區域私人連線。
4. 以四檔完成「本機更新 → 雲端持久保存 → 程式重啟讀回 → 正式網頁呈現」；先列出固定小批請求預算，所有失敗與重試計入，等待不冒充來源失敗。
5. 驗證本機停止後的雲端讀取、重新啟動接續、舊資料警示與錯誤恢復，以及現金流服務回歸。通過後才逐步擴大。

2026-10-09／10-11 查詢時，既有 `small-budget-cashflow-api` 為 Starter、0.5 CPU、512 MB RAM、新加坡、1 GB 持久磁碟，當時沒有 Render PostgreSQL。這是歷史盤點，下一次執行前重查。持久磁碟不是受管 PostgreSQL，也未驗證剩餘可用磁碟與帳單額度。

參考來源（2026-10-11 查核，採購前重查）：[Render 運算費用](https://render.com/articles/production-rails-hosting-guide)、[Render 儲存與其他費用](https://render.com/articles/how-much-does-cloud-application-hosting-cost-for-small-businesses)。

## 第三階段：全市場與正式網站驗收

1. 每次用官方上市／上櫃動態母體，歷史的 1,977 檔只作背景。先核對代碼差異，不把 1,985 合成測試或以前的 1,986 當當前母體。
2. 日行情與籌碼優先全市場批次；營收、財報依發布／訂正事件更新，日曆與來源日期可稽核。使用者沒有要讓客戶下載資料庫。
3. 首次回補與每日增量分開制定來源請求預算、時窗及停止條件。FinMind 額度與商業使用資格是獨立前置條件；只在資格確認後納入正式資料管線，不自動購買方案。官方來源缺漏的欄位逐項列出。
4. 全部股票都有處理結果，欄位完整、缺漏、不適用、新上市歷史不足、停牌、來源失敗分開記錄。95% 建檔不能冒稱使用者要求的完整資料通過。RSS 是新聞候選，不等於每家公司每天有新聞、全文研究或情緒分析。
5. 六榜保留原有證據門檻；來源失敗／未解決分類不能清除或降門檻換取通過。
6. 正式桌面與手機實際操作各分頁、圖表、來源日期、進度、缺漏及錯誤／重試。資料庫計算完成之外，前端必須讀到同一快照與實際數值，不能以後台成功結案。
7. 量測讀 API、背景計算與外部來源各自耗時，避免把平台執行上限或來源額度歸因 PostgreSQL 容量。驗證讀網頁不增加来源請求。
8. 驗收首次全市場和下一個獨立每日週期，保留 jobId、交易日期、母體、完整／缺漏／失敗數、快照批次及前端證據。
9. 逐一核對 repo SHA、Actions build／deploy、Pages HTTP／實際內容、AppDeploy 正式 API。平台 E2E 未提供時如實記錄，不能以本機 Playwright 或 `ready` 代替。
10. 雲端資料完整、可讀回且備份／恢復驗證通過後，另行確認是否移除本機舊四檔測試資料庫。現有 `.cache/refresh-pg` 不在本次清理範圍。
